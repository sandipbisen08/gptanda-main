# तांडा ग्रामपंचायत - Official Website

## Tand Grampanchayat Official Website

A modern, responsive website for Tand Grampanchayat built with React, TypeScript, and SCSS.

### Features

- ✅ **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- ✅ **Modern UI/UX** - Beautiful and intuitive user interface
- ✅ **Marathi Language** - Complete website in Marathi language
- ✅ **Multiple Pages** - Home, About, Services, and Contact pages
- ✅ **Contact Form** - Interactive contact form for inquiries
- ✅ **Mobile Menu** - Responsive navigation menu for mobile devices
- ✅ **Smooth Animations** - Engaging animations and transitions
- ✅ **SEO Optimized** - Meta tags and proper HTML structure

### Tech Stack

- **Frontend Framework**: React 18
- **Language**: TypeScript
- **Styling**: SCSS/SASS
- **Routing**: React Router v6
- **Icons**: React Icons
- **Build Tool**: Create React App

### Installation

1. **Clone the repository** (or navigate to the project directory)
   ```bash
   cd tand-grampanchayat
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to `http://localhost:3000` to view the website

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs the test suite
- `npm eject` - Ejects from Create React App (irreversible)

### Customization

To customize the website:

1. **Update Colors**: Modify CSS variables in `src/styles/main.scss`
2. **Change Content**: Edit text in respective page components
3. **Add Images**: Place images in `public/images/` folder
4. **Update Contact Info**: Modify contact details in `Footer.tsx` and `Contact.tsx`
